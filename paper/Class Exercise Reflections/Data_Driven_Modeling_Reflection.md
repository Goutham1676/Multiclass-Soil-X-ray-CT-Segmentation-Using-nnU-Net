## Reflection

In this module, I started with exploratory data analysis using historical weather data from Open-Meteo. I learned how to access data through APIs, calculate summary statistics, examine trends, and understand how sample size affects uncertainty. In the second part, I explored classification, regression, and clustering using the wine dataset. One important takeaway was that having more features does not necessarily improve model performance, especially with limited observations. In the third part, I used TPOT to automate model selection and compared its performance with simpler models. TPOT did not show much improvement over logistic regression, which made me realize that more complex models are not always necessary.

The fourth part was particularly challenging because I was relatively new to running jobs on HPCC. Initially, I copied the entire Bash script into the terminal instead of saving it as a Slurm submission file and running it using sbatch submit_tpot_array.sb. I later understood the difference between executing commands directly and submitting jobs through Slurm. I also encountered errors with existing output directories while rerunning jobs. After resolving these issues, I successfully ran four TPOT searches with different random seeds and compared their results.

Overall, these exercises helped me understand the importance of choosing appropriate models, keeping test data separate, and documenting experiments so they can be reproduced. I can apply these lessons to my soil CT segmentation research, particularly when working with limited annotated data and evaluating models on new samples.
